# actions-manager-demo-repository

This repository will be a demo repository for an application that runs github acitons.

The workflows
- 50 action workflows
- run at random times and fail randomly.
- never run over 30 seconds.
- Spread out so they will run in TOTAL for 10 minutes a month for ALL actions.
- Some of them disabled.
- Some of them possible to trigger manually.
- Have multiple jobs the log random stuff
- on a uniform schedule, so they all run within a period of a week.
- All have random failures.

This is meant to simulate a real world large devops operation that includes world wide CI and CD of multiple systems as well as many automated devops workflows and operational workflows.
